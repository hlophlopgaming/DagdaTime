# Draugr Time v0.2.2 — lower memory usage

This release reduces memory retained by tag undo, Week and Reports, and fixes
reports and JSON history export for ranges containing more than 100,000 events.

- Tag undo stores typed changes only for affected rows, preserving up to 20
  actions without copying the entire tag history. Conflicting edits reject undo
  atomically; independent newer records remain intact.
- Week retains compressed color bands and caches canvas geometry. Daily
  timesheets retain totals rather than full tracks or duplicate reports.
- Report history loads in event batches, shares repeated labels through Arc<str>
  and merges intervals before allocating strings.
- Leaving Week/Reports frees loaded data and caches, invalidates pending results
  and reclaims freed allocator pages on Linux/glibc. Tray and away-tag navigation
  receive the same cleanup.
- Large reports and JSON archive export no longer hit the 100,000-event cap.
  The localhost raw-event API retains its safety limit.

Synthetic Linux release measurements: Week open-window PSS decreased from
76.55 to 35.62 MiB; a monthly CLI report with 93,031 events decreased peak RSS
from 159.65 to 26.62 MiB, with identical CSV output. These are fixture results,
not guaranteed memory limits for personal history. Window buffers still scale
with window size and are released when the window closes.

All data remains local. No database migration or new dependency is required.
Each platform archive contains the desktop app and draugr-time-cli.

## Validation and limitations

Local fmt, clippy with warnings denied and tests passed: 174 tests, 0 failures,
7 environment-dependent tests ignored. Native Wayland Week smoke and X11
benchmark runs passed. GitHub CI checks Linux, Windows and macOS before release.
See docs/desktop-memory.md for measurements and reproduction details.

Week's 1,440 elapsed-time bins approximate subminute visual detail; numeric
reports and Day selection remain exact. Real Windows/macOS desktop interactions,
1440p/4K windows and CJK/emoji fallback-font usage need manual verification.
