# Draugr Time 1.0

- Two-screen first-run setup explains local collection/storage, offers permission
  hints and starts recording into the Day view.
- Application icons for Windows executables, the macOS app bundle and Linux
  desktop menus, alongside the existing window/tray icons.
- Built-in headless CLI on Linux/macOS: `draugr-time report`, `export`, `import`,
  `status`, and `--help`. Windows keeps `draugr-time-cli.exe`.
- Minimal privacy: excluded applications, confirmed range deletion and an optional
  local weekday/everyday recording schedule.
- Improved Reports/Overview legend layout and timeline scrolling.

Download the archive for your OS and extract it before launching. On macOS use
`Draugr Time.app`; on Windows/Linux use the desktop executable. On Linux, choose
**Add to application menu** after extracting to a permanent folder.

History remains local. No telemetry, browser extension or network updater.
Installers are planned for 1.1; backups and title masking remain later work.
Windows/macOS downloads are not publisher-signed/notarized. Real OS permission,
login and fresh-archive verification steps are listed in [M10](https://github.com/hlophlopgaming/DraugrTime/blob/v1.0.0/docs/m10.md).
