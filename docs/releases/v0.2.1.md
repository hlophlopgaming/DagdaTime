# Draugr Time v0.2.1

This release fixes the Windows locale-provider clippy failure found in the
v0.2.0 candidate. macOS passed that candidate’s build/runtime checks; the
corrected release is checked again on all three platforms.

This release adds the Day overview, Week view, monthly reports and timesheets,
local CSV/JSON export, ActivityWatch import and a headless console executable.

- Two-level project → application donut with duration/share legend, pointer and
  keyboard highlighting, explicit untagged/unknown activity and small-slice expansion.
- Reports grouped by project, application or document; day/week/month/custom local
  dates, project filtering, daily timesheets, clipboard copy and CSV/JSON export.
- Atomic history import with validation and ID remapping. Conflicting event
  histories are rejected without partial insertion or overwriting existing data.
- `draugr-time-cli`: status, reports, export and import without a desktop session.
  Both GUI and CLI are included in each downloadable platform archive.
- Regex auto-tagging, priority resolution, live preview, apply-to-history and undo.
- Eight locally bundled interface languages with system detection and saved choice.
- Supplied Draugr logos in the interface/README and crown tray icon with state colors.
- Linux tray without GTK3, lower closed-window memory usage and resizable Day panels.

All application data remains local. Machine-readable timestamps are UTC Unix
milliseconds; calendar reports respect local midnight and daylight-saving changes.
The owner's October report was verified separately and is not part of this release.

## Validation and platform notes

Local `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and
`cargo test` passed: 161 tests, with 7 environment-specific checks ignored by
default. The serial native rendering check passed for all eight languages,
light/dark themes and the narrow layout. Tests cover month lengths/leap years,
monthly/daily parity, DST, imports, CLI failures and original logo alpha masks.

Linux/Wayland fixture checks and authenticated localhost CLI status passed.
GitHub CI builds and checks Linux, Windows and macOS before attaching release assets.
Actual macOS permissions, sleep/reboot behavior, platform file pickers and native
tray contrast still need real-session verification; see docs/m6.md and docs/m7.md.

This is an early release. GUI reports cover at most 366 days; the existing
100,000-event query cap remains. ActivityWatch imports support currentwindow,
afkstatus and web.tab.current buckets, and reject overlapping host histories.
Browser-extension capture, installers, backups and onboarding remain planned.
