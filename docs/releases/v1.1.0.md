# Draugr Time 1.1.0

Installers for the first time, alongside the existing portable archives.

## What's new

- **Windows:** a per-user installer (Inno Setup) installs the desktop app and the
  `draugr-time-cli` console tool, adds the CLI to your command line (PATH), and
  creates Start-menu and optional desktop shortcuts. A portable zip is still
  published if you prefer to run without installing.
- **macOS:** `Draugr Time.app` now ships in a DMG with a link to Applications for
  drag-and-drop install.
- **Linux:** an AppImage bundles the desktop app, launcher entry and icon.
- The About panel (Settings) links to the GitHub repository and credits the
  creator, **hlophlopgaming**, with links that open in your browser.

## Install

- **Windows:** run `Draugr-Time-...-Windows-Setup.exe`, or extract the portable
  zip and run `draugr-time.exe`.
- **macOS:** open the DMG and drag `Draugr Time.app` to Applications. The app is
  ad-hoc signed, not Developer ID signed/notarized; macOS may ask you to open it
  via Privacy & Security → Open Anyway.
- **Linux:** make the AppImage executable and run it, or use the portable archive
  and its **Add to application menu** action.

Uninstalling leaves your history in place (Windows
`%LOCALAPPDATA%\DraugrTime`, macOS `~/Library/Application Support/DraugrTime`,
Linux `~/.local/share/DraugrTime`) unless you delete it yourself.

History remains local. No telemetry, browser extension or network updater.
Flatpak is deferred to a later release; Windows/macOS installers are not
publisher-signed/notarized.
