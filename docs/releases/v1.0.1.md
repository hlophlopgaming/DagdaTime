# Draugr Time 1.0.1

- The open window wakes once per second only when it has something to load: a day
  that has not been shown yet, or the Day screen while it shows today. A loaded
  past day, Settings, Tags, Rules, Week, Reports, Overview and the preview stay
  idle, so a mostly-hidden tracker uses less CPU.
- Leaving the Day screen pauses today's refresh; returning to it resumes within a
  second. Closing the window already paused it.
- On Linux the system theme now follows the desktop portal's change signal
  instead of polling every two seconds.
- Optional GPU rendering: build with `--features gpu` to use the wgpu renderer,
  with automatic fallback to tiny-skia; `ICED_BACKEND=tiny-skia` forces software
  rendering. Default builds are unchanged.
- `scripts/measure_idle.py <pid> [seconds]` reports CPU, wakeups, threads and
  PSS/RSS for comparing builds on the same machine.

Download the archive for your OS and extract it before launching. On macOS use
`Draugr Time.app`; on Windows/Linux use the desktop executable. On Linux, choose
**Add to application menu** after extracting to a permanent folder.

History remains local. No telemetry, browser extension or network updater.
Installers are planned for 1.1; backups and title masking remain later work.
Windows/macOS downloads are not publisher-signed/notarized.
