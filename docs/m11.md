# M11 — Release 1.1: installers

## What ships

| OS | Artifact | Contents |
|---|---|---|
| Windows | `Draugr-Time-…-Windows-Setup.exe` (Inno Setup) | `draugr-time.exe`, `draugr-time-cli.exe`, CLI on PATH, shortcuts |
| Windows | `Draugr-Time-…-Windows-x86_64.zip` (portable) | both executables |
| macOS | `Draugr-Time-…-macOS.dmg` | `Draugr Time.app` + `/Applications` link |
| Linux | `Draugr-Time-…-Linux-x86_64.AppImage` | desktop binary, AppRun, desktop entry, icon |
| Linux | `Draugr-Time-…-Linux-x86_64.tar.gz` (portable) | binary, `.desktop`, hicolor icon |

Flatpak is deferred (see PLAN "Later"); the app remains unsigned/notarized on
Windows and macOS.

## Installer behavior

- The Windows installer is per user (`PrivilegesRequired=lowest`), installs to
  `%LOCALAPPDATA%\Programs\Draugr Time`, and appends that folder to the user
  `Path` (HKCU\Environment) only when not already present. The uninstaller
  removes just the installed files; history in `%LOCALAPPDATA%\DraugrTime` is
  never touched.
- The AppImage is self-contained; deleting the file removes it. The portable
  archive keeps the in-app **Add to application menu** action.
- The DMG drag-installs the `.app`; deleting it from Applications leaves
  `~/Library/Application Support/DraugrTime` in place.

## Local verification

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`
  and `python -m unittest discover -s tests` all pass. The Python suite covers
  the macOS bundle, the Windows installer script (CLI + PATH), the AppImage
  AppDir layout (AppRun/desktop/icon) and the CI installer steps.

## Needs manual verification on a real OS

1. **Windows:** run the installer as a normal user, confirm the Start-menu and
   optional desktop shortcut, that `draugr-time-cli --help` works in a new
   terminal (PATH update), onboarding reaches the Day view, and that uninstalling
   leaves `%LOCALAPPDATA%\DraugrTime` (history) intact.
2. **macOS:** open the DMG, drag to Applications, launch (allow via
   Privacy & Security → Open Anyway since the app is ad-hoc signed), complete
   onboarding, then delete the `.app` and confirm
   `~/Library/Application Support/DraugrTime` remains.
3. **Linux:** `chmod +x` the AppImage, run it, complete onboarding to the Day
   view, and confirm the icon/entry appear when integrated. Verify on X11 and,
   where available, Wayland.
